恒科 / 上证 / 自选基金·股票 · 桌面浮窗
====================================

安装位置
  C:\Users\xtljf\Tools\hstech-float\

怎么启动
  双击 start_hstech_float.vbs（无黑窗口）

怎么退出
  浮窗右键 → 退出

界面
  右下角半透明多行：上证 / 恒科 固定在最上；
  其下为自选基金或股票；末行「合计」汇总有本金的盈亏。
  左键拖动；双击缩成细条；开盘约 4 秒刷新，收盘后约 15 分钟探一次。
  颜色：A 股习惯，红涨绿跌（含盈亏与合计）。

怎么添加 / 删除自选
  右键浮窗 →「设置持仓…」
  · 列表可改「标签」「代码」「本金」；点「删」去掉一行
  · 底部输入代码 →「添加」：自动识别基金或股票并填短名
  · 本金可留空或 0：只盯涨跌，不进合计
  ·「保存」写入 holdings.json 并立刻刷新浮窗

代码怎么认
  · 6 位基金代码（如 017435）：持仓加权估值 + 可选本金盈亏
  · 6 位 A 股 / ETF（如 600519、588000）：实时价与涨跌%；有本金则 本金×涨跌%
  · 5 位或 HK 前缀：按港股行情
  · 显式 sh/sz 前缀可强制走股票行情

配置 holdings.json（与脚本同目录）
  新格式示例：
  {
    "version": 2,
    "items": [
      {"code": "017435", "kind": "fund", "label": "港股消费", "amount": 37386},
      {"code": "161725", "kind": "fund", "label": "白酒", "amount": 8182},
      {"code": "011612", "kind": "fund", "label": "科创50", "amount": 3734},
      {"code": "600519", "kind": "stock", "label": "茅台", "amount": 10000}
    ]
  }
  旧版 { "017435": 38000, ... } 仍可读取，保存后会升级为上述结构。

基金估值方法
  估值涨跌% ≈ Σ( 持仓占比% × 标的实时涨跌% )
  估值净值 ≈ 最新已披露单位净值 × (1 + 估值涨跌%)
  内置模板：017435 港股消费、161725 白酒、011612 科创50（联接含目标 ETF）；
  其它基金（含联接）启动时拉东财 F10，联接自动补目标 ETF。仅为盯盘近似。

收盘估值日志与误差对比
  · 文件：同目录 estimates_log.csv（Excel 可直接打开）
  · 何时写入（按基金分别判断，上海时区；同日同代码不覆盖）：
      - A 股 / 内地持仓为主：工作日 15:05 后写入
      - 港股相关（名称含港股/恒生/恒科/沪港深，或持仓港股权重≥30%，
        如 017435 港股消费）：工作日 16:10 后写入（等港股收盘）
  · 官方回填：收盘后轮询，或右键「估值误差…」→「回填官方净值」；
    从东财 lsjz 取当日单位净值与日涨跌%，计算
      误差% = 官方涨跌% − 估值涨跌%（正=实际比白天估值高）
      误差净值 = 官方净值 − 估值净值
  · 查看：右键 →「估值误差…」看近几日对照表；或「打开日志目录」/「打开 CSV」
  · 也可在对话框点「记下当前估值」补记今日尚未写入的基金（仍不覆盖已有行）

开机自启（可选）
  Win+R → shell:startup → 放入本目录 .vbs 的快捷方式

数据：新浪实时行情 + 东财基金净值/搜索。仅供个人参考。
